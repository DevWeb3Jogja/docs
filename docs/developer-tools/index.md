# Developer Tools

Kumpulan tools dan library yang berguna untuk development Web3.

## Tools yang Tersedia

### Ponder
Framework indexing blockchain untuk membuat backend API dApp. Ponder mendengarkan event smart contract, memproses data, dan menyediakan GraphQL API.

[Pelajari Ponder →](/developer-tools/ponder)

### Viem
TypeScript library modern untuk berinteraksi dengan Ethereum. Alternative lightweight untuk ethers.js dan web3.js.

[Pelajari Viem →](/developer-tools/viem)

## Kenapa Tools Ini Penting?

Developer tools yang tepat dapat mempercepat development dan meningkatkan kualitas aplikasi. Tools di kategori ini sudah di-battle test di production dan recommended untuk proyek Web3 modern.
