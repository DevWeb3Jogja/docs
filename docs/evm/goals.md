# Tujuan Pembelajaran (Goals)

Setelah menyelesaikan materi ini, kamu akan mampu:

## 🎯 Skill yang akan dikuasai

### 1. Setup Development Environment
- Menginstall dan menggunakan **Foundry** sebagai development framework
- Mengintegrasikan library **OpenZeppelin** ke dalam project

### 2. Memahami Konsep Dasar
- Memahami standar **ERC20** dan cara kerjanya
- Memahami pattern **Ownable** untuk access control
- Memahami vulnerability **Reentrancy** dan cara pencegahannya

### 3. Implementasi Smart Contract
- Membuat token ERC20 sendiri dengan nama, symbol, dan supply yang custom
- Membuat kontrak **Vault** yang dapat menerima token dan menghitung shares

### 4. Testing Smart Contract
- Menulis unit test untuk smart contract menggunakan Foundry
- Menggunakan verbosity untuk debugging

## 📦 Hasil Akhir

Di akhir pembelajaran, kamu akan memiliki:

1. **MyToken.sol** - Kontrak ERC20 token custom
2. **Vault.sol** - Kontrak vault untuk deposit dan withdraw token
3. **Test files** - Unit test untuk kedua kontrak

## ⏱️ Estimasi Waktu

- **Pemula**: 4-6 jam
- **Sudah familiar dengan programming**: 2-3 jam
