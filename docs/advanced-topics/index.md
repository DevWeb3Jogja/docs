# Advanced Topics

Topik-topik advanced untuk developer Web3 yang ingin mendalami konsep dan teknologi lebih lanjut.

## Topik yang Tersedia

### Uniswap V4 Hooks
Pelajari cara membuat custom hooks untuk Uniswap V4, DEX paling populer di Ethereum. Hooks memungkinkan modifikasi behavior liquidity pool tanpa fork.

[Pelajari Uniswap V4 Hooks →](/advanced-topics/uniswap-v4-hooks)

### UUPS Upgradeable Pattern
Implementasi smart contract yang bisa di-upgrade menggunakan pattern UUPS (Universal Upgradeable Proxy Standard). Lebih efisien dibanding Transparent Proxy.

[Pelajari UUPS Pattern →](/advanced-topics/uups-upgradeable)

### x402 Protocol
Protocol HTTP payment native untuk Web3. Memungkinkan micropayment per-request tanpa subscription atau friction tinggi.

[Pelajari x402 Protocol →](/advanced-topics/x402-protocol)

- Foundry atau Hardhat
- Konsep dasar DeFi dan Web3
